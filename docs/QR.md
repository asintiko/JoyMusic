# Joy Code: брендированный QR

Пакет `@joymusic/qr` (`packages/qr`) рисует «Joy Code»: печатный QR-код заведения со скруглёнными модулями, фирменными глазами, логотипом в центре и рамкой «Scan · Order · Dance». Всё считается чистым JS и работает и в Node, и в браузере. Ядро не трогает DOM.

Логотип пакет не тянет из `@joymusic/brand`. Его передаёт вызывающий код строкой SVG.

## Точки входа

| Импорт                 | Что даёт                                                                          |
| ---------------------- | --------------------------------------------------------------------------------- |
| `@joymusic/qr`         | Ядро: кодирование, SVG, шаблоны, PDF из готовых PNG, `createExporter`             |
| `@joymusic/qr/node`    | Ядро плюс растеризация через `@resvg/resvg-js`: `renderPng`, `renderPdf` и другие |
| `@joymusic/qr/browser` | Ядро плюс растеризация через `canvas`: те же функции, что и в `node`              |

`@resvg/resvg-js` стоит в `optionalDependencies` и подгружается лениво, поэтому импорт `node` не падает там, где бинарник не собрался.

## Быстрый старт

```ts
import { readFileSync } from "node:fs";
import { encodeQr, renderJoyCode, renderTemplate } from "@joymusic/qr";
import { renderPng, renderTablesPdf } from "@joymusic/qr/node";

const logo = { svg: readFileSync("mark.svg", "utf8") };
const matrix = encodeQr("https://joymusic.uz/v/bar-nuri?t=Xk3fA9qLmP2z");

const svg = renderJoyCode(matrix, { theme: "club", logo, footer: "Stol 7" });

const layout = renderTemplate(matrix, {
  template: "poster",
  theme: "lounge",
  locale: "uz",
  venueName: "Bar Nuri",
  tableNumber: 7,
  logo,
  bleedMm: 3,
  cropMarks: true,
});
const png = await renderPng(layout, { dpi: 300 });
```

## API

### Кодирование

- `encodeQr(text, { ecc?, minVersion?, maskPattern? }): boolean[][]`. По умолчанию `ecc: "H"`. Матрица без рамки: `true` это тёмный модуль.
- `encodeQrDetailed(text, options): { matrix, size, version, ecc, maskPattern }`.

Под капотом лёгкая MIT-библиотека `uqr`. Результат детерминирован.

### SVG

`renderJoyCode(matrix, options): string`. Возвращает готовый SVG. Весь текст в нём превращён в контуры, шрифты на машине не нужны.

| Опция         | Значения                                       | По умолчанию               |
| ------------- | ---------------------------------------------- | -------------------------- |
| `theme`       | `"club"`, `"lounge"`, `"cafe"` или свой объект | `"club"`                   |
| `gradient`    | `boolean`, градиент на модулях                 | из темы (включён)          |
| `moduleStyle` | `"rounded"`, `"dots"`, `"square"`              | `"rounded"`                |
| `eyeStyle`    | `"rounded"`, `"circle"`, `"square"`            | `"rounded"`                |
| `logo`        | `{ svg, viewBox? }`                            | нет                        |
| `logoScale`   | доля стороны кода под логотип                  | `0.28`, потолок по площади |
| `quietZone`   | тихая зона в модулях, не меньше 4              | `4`                        |
| `frame`       | `false` отдаёт только панель с кодом           | `true`                     |
| `headline`    | строка или `false`                             | «Scan · Order · Dance»     |
| `locale`      | `"uz"`, `"ru"`, `"en"` для заголовка           | нет (английский)           |
| `footer`      | строка под кодом, обычно «Stol 7»              | нет                        |
| `idPrefix`    | префикс `id` внутри SVG                        | `"jc"`                     |
| `title`       | подпись для доступности                        | `"Joy Code"`               |

`logo.svg` может быть целым документом `<svg viewBox=...>` или фрагментом с явным `viewBox`. Идентификаторы градиентов внутри логотипа получают префикс, конфликтов при нескольких кодах на странице нет.

### Темы

Три пресета лежат в `joyThemes`. Свою тему задаёт объект `{ base?, ...поля JoyPalette }`, недостающие поля берутся из `base` (по умолчанию `club`).

Поля палитры: `canvas`, `canvasAlt` (фон рамки), `panel` (светлая подложка кода), `modules`, `modulesEnd` (градиент модулей), `eye`, `eyeCore`, `accent`, `accentEnd` (градиент заголовка и обводок), `text`, `textMuted`, `gradient`.

Правило для своих тем: модули и глаза должны быть тёмными на светлой подложке. Контраст не ниже 4,5 : 1, проверка `contrastRatio(a, b)` и константа `minimumModuleContrast` экспортируются. Пресеты тестом гарантированно проходят.

### Шаблоны для печати

`renderTemplate(matrix, options): PrintLayout`. Опции шаблона расширяют стилевые опции выше и добавляют:

| Опция         | Смысл                                                            |
| ------------- | ---------------------------------------------------------------- |
| `template`    | `"table-tent"`, `"sticker"`, `"poster"`, `"tv-overlay"`          |
| `venueName`   | название заведения                                               |
| `tableLabel`  | готовая подпись стола («Stol 7»)                                 |
| `tableNumber` | номер стола: подпись соберётся по `locale` (Stol / Стол / Table) |
| `bleedMm`     | вылет под обрез, мм (для печати обычно 3)                        |
| `cropMarks`   | метки реза в припуске 8 мм за вылетом                            |

`PrintLayout` содержит `svg`, `unit` (`"mm"` или `"px"`), `width`, `height`, `trimWidth`, `trimHeight`, `bleedMm`, `slugMm`, `widthMm`, `heightMm`, `missingGlyphs`. `width` и `height` это полная страница вместе с вылетом и метками.

Вспомогательные: `pixelSize(layout, dpi = 300)`, `templateSpecs`, `printTemplates`, `formatTableLabel(locale, номер)`.

### Растр и PDF

`@joymusic/qr/node` и `@joymusic/qr/browser` экспортируют одинаковый набор:

- `renderPng(layout, { dpi = 300, background? }): Promise<Uint8Array>`. В файл пишутся метаданные dpi (`pHYs`), типография увидит честные 300.
- `renderPdf(layout, { dpi, title, author, createdAt }): Promise<Uint8Array>`. Страница ровно по физическому размеру, внутри PNG 300 dpi.
- `renderBatchPdf(layouts, options)`. Многостраничный PDF из готовых макетов.
- `renderTablesPdf({ ...опции шаблона, tables: [{ url, tableNumber | tableLabel }] }, options)`. Пакет «все столы» одним вызовом. Для предпросмотра без растра есть `buildTableLayouts(input)` из ядра.

Для других сред: `createExporter(rasterizer)` принимает функцию `({ svg, width, height, background }) => Promise<Uint8Array>` и возвращает тот же набор. `createPdfFromPngs(pages, options)` собирает PDF из готовых PNG.

## Размеры печати

| Шаблон       | Размер                             | Состав                                                                          |
| ------------ | ---------------------------------- | ------------------------------------------------------------------------------- |
| `table-tent` | 105 × 296 мм, развёртка из двух A6 | Две панели по 105 × 148 мм, верхняя повёрнута на 180°, пунктир сгиба посередине |
| `sticker`    | круг 80 мм (квадрат 80 × 80)       | Код в центре, заголовок по верхней дуге, «стол · заведение» по нижней           |
| `poster`     | A4, 210 × 297 мм                   | Название, карточка с кодом и столом, три шага                                   |
| `tv-overlay` | 1920 × 1080 px, прозрачный фон     | Карточка в правом нижнем углу, название заведения под кодом                     |

С вылетом 3 мм и метками реза страница A4 становится 232 × 319 мм. Для круглого стикера метки заменяются пунктирным контуром реза.

## Советы по печати

- Просите у типографии PDF в исходном размере. Внутри PNG 300 dpi, масштабировать его не нужно.
- Вылет 3 мм и метки реза включайте только для типографской печати. Для домашнего принтера и предпросмотра оставляйте выключенными.
- Тейбл-тент: сложите по пунктиру. Верхняя половина повёрнута, поэтому обе стороны читаются с нужной стороны.
- Плёнка и глянец дают блики. Для стикеров на столе берите матовую ламинацию.
- Проверяйте напечатанный код с двух-трёх телефонов до тиража. Печатайте пробный лист из настоящего заведения при его освещении.
- Минимальная физическая сторона модуля 0,5 мм. Стикер 80 мм при типичном URL даёт около 1 мм на модуль. Длинные URL раздувают версию кода и уменьшают модуль, поэтому держите ссылку короткой.
- ТВ-оверлей отдаётся с прозрачным фоном. Сканеру нужна светлая подложка кода, она уже внутри карточки.

## Правила безопасной сканируемости

1. Уровень коррекции только `H`. Функция `encodeQr` включает его по умолчанию.
2. Логотип закрывает не больше 18 % площади кода: константа `MAX_LOGO_AREA_RATIO`, функция `logoCutout(size, scale)`. Запрос больше потолка молча урезается. Вырез всегда нечётный по модулям, симметричный и не задевает три поисковых узора.
3. Тёмные модули на светлой подложке. Инвертированный код (светлый на тёмном) пакет не рисует.
4. Тихая зона не меньше 4 модулей. Значение ниже 4 поднимается до 4.
5. Контраст модулей и подложки не ниже 4,5 : 1 (см. темы).
6. Стиль `dots` оставлен для декоративных вывесок: круги касаются друг друга, но декодеры читают его хуже, чем `rounded`. Для столов берите `rounded`.
7. Ссылку кодируйте короткой: чем короче текст, тем ниже версия, крупнее модуль и больше запас.

Что проверяют автотесты: каждый шаблон в каждой теме растеризуется и разбирается декодером `jsqr`, URL возвращается без потерь. Ещё проверяются варианты с вылетом и метками, три языка, все стили модулей и глаз, длинный URL, потолок логотипа, битовый уровень коррекции в самой матрице, детерминизм SVG (снимок `tests/__snapshots__/joycode-club.svg`), размеры страниц PDF и метаданные dpi в PNG.

## Шрифты и текст

Заголовки набраны Unbounded 700, подписи Manrope 500 и 700. Оба шрифта из `@fontsource` вшиты в `src/fonts/data.ts` в base64 (подмножества latin и cyrillic). Обновить их можно командой `pnpm --filter @joymusic/qr fonts:embed`. Текст превращается в контуры через `opentype.js`, поэтому SVG, PNG и PDF выглядят одинаково везде.

Узбекская латиница: знаки `ʻ` (U+02BB) и `ʼ` (U+02BC) есть в Unbounded. Если основного шрифта не хватает, символ ищется в запасном семействе, затем среди подстановок (`ʻ` → `‘`, `ʼ` → `’`, `·` → `•`). Узбекская кириллица `қ ғ ҳ` в подмножестве `cyrillic` отсутствует, поэтому рисуется базовой буквой (`к г х`). Неизвестный символ становится пробелом. Все подмены попадают в `PrintLayout.missingGlyphs`, так что админка может предупредить владельца.
