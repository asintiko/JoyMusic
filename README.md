# Joy Music

Платформа заказа музыки у диджея по QR-коду для баров, клубов и кафе.

Гость сканирует Joy Code в заведении, находит трек и заказывает его. Диджей видит очередь заказов и играющий трек в десктопном приложении. Владелец управляет заведениями, QR-кодами, диджеями и аналитикой в админ-панели.

## Состав

| Путь                 | Назначение                            |
| -------------------- | ------------------------------------- |
| `apps/api`           | REST и WebSocket API                  |
| `apps/web`           | Лендинг, гостевой PWA, экран для ТВ   |
| `apps/admin`         | Админ-панель                          |
| `apps/desktop`       | Приложение диджея для Mac и Windows   |
| `packages/shared`    | Контракты, клиент API, состояние зала |
| `packages/ui`        | Дизайн-система                        |
| `packages/catalog`   | Поиск музыки, транслитерация          |
| `packages/dj-bridge` | Определение играющего трека, MIDI     |
| `packages/qr`        | Joy Code и макеты для печати          |
| `packages/brand`     | Логотип, иконки, ассеты               |

## Команды

```
pnpm install
pnpm dev
pnpm verify
```

`pnpm verify` запускает проверку отсутствия комментариев, форматирование, lint, типы и тесты.

Подробности архитектуры в `docs/ARCHITECTURE.md`.
